AI GAME FINDER SETUP
====================

Frontend endpoint is already configured:
https://icons-6.us/game-ai.php

1) Upload backend/php/game-ai.php to:
   /home/icons-6.us/public_html/game-ai.php

2) Configure OPENAI_API_KEY on the server environment.
   NEVER put the API key in GitHub, ai-config.js, HTML, or public files.

3) Frontend config is already set in assets/ai-config.js:
   window.AI_GAME_FINDER_ENDPOINT = "https://icons-6.us/game-ai.php";

4) game-ai.php only allows browser requests from:
   https://1v1-lol-unbloked.github.io

5) Test after deployment by using the AI Game Finder on the site.
   If the API is unavailable, the frontend falls back to the local smart matcher.
