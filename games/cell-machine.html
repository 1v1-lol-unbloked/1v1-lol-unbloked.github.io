Cell Machine

Overview

About Cell Machine

Under the hood it's Unity WebGL, put together by Sam Hogan. Cell Machine is a puzzle games pick for anyone who'd rather plan two steps ahead than button-mash. Roughly 20M+ plays and counting — not a hidden gem exactly.

How to Play Cell Machine

Cell Machine's controls aren't documented on our end. Try the obvious stuff first — WASD, arrows, click, space — the game usually makes it clear once you're moving.

Tips for Cell Machine

  • Undo a mistake early. Letting it snowball is usually worse than starting the move over.
  • There's rarely a clock forcing your hand — take the extra few seconds to think.
  • If the obvious move isn't working, the answer is probably hiding in whatever mechanic you've been ignoring.

Why Play Cell Machine Here

Nothing extra bolted on — just Cell Machine, ready to go.

Cell Machine FAQ

Can I play Cell Machine in a browser?

Yes. This page runs the browser version directly.

Do I need to install anything for Cell Machine?

No. It's built with Unity WebGL, so it just runs once the page loads.
