Cluster Rush

Overview

About Cluster Rush

Somewhere around 10M+ plays so far, for what that's worth. Cluster Rush puts you behind the wheel in a endless runner games setup where timing beats flooring it. SlashRoll built it, running on Unity WebGL.

How to Play Cluster Rush

Cluster Rush's controls aren't documented on our end. Try the obvious stuff first — WASD, arrows, click, space — the game usually makes it clear once you're moving.

Tips for Cluster Rush

  • Braking a beat before the turn, not during it, keeps you from losing control.
  • The first stretch usually plays out the same way each run — learn it and the rest gets easier.
  • Small corrections beat sharp ones almost every time.

Why Play Cluster Rush Here

Nothing extra bolted on — just Cluster Rush, ready to go.

Cluster Rush FAQ

Can I play Cluster Rush in a browser?

Yes. This page runs the browser version directly.

Do I need to install anything for Cluster Rush?

No. It's built with Unity WebGL, so it just runs once the page loads.
