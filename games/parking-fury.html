About Parking Fury

Parking Fury is a parking games game where the difference between a clean run and a wipeout is usually one late input. Credit for this one goes to Andriy Pidvirnyy — it's built on HTML5, JavaScript. It's picked up around 50M+ plays over time, so plenty of people have already run into it.
