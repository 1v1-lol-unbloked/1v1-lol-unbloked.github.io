About Soccer Skills Euro Cup

Soccer Skills Euro Cup is a sports arcade games game where the difference between a clean run and a wipeout is usually one late input. Somewhere around 50M+ plays so far, for what that's worth. It's a HTML5, JavaScript title, made by Radical Play.
