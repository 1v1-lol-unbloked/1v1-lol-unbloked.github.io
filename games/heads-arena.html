Heads Arena

Overview

About Heads Arena

Roughly 50M+ plays and counting — not a hidden gem exactly. Heads Arena is a soccer games game where the difference between a clean run and a wipeout is usually one late input. It's a HTML5, JavaScript title, made by Poki.

How to Play Heads Arena

The control scheme for Heads Arena:

  • Arrow Keys: Move (Player 1)
  • Space: Shoot (Player 1)
  • WASD Keys: Move (Player 2)
  • Q: Shoot (Player 2)

Tips for Heads Arena

  • Braking a beat before the turn, not during it, keeps you from losing control.
  • The first stretch usually plays out the same way each run — learn it and the rest gets easier.
  • Small corrections beat sharp ones almost every time.

Why Play Heads Arena Here

Same layout as everything else in the catalog, so if you bounce off Heads Arena, the next one's one click away.

Heads Arena FAQ

Can I play Heads Arena in a browser?

Yeah — it loads right from this page, nothing to download.

Do I need to install anything for Heads Arena?

No. It's built with HTML5, JavaScript, so it just runs once the page loads.

Can two people play Heads Arena at once?

Yes, on the same keyboard — look at the controls above, there's usually a separate key set listed for each player.
