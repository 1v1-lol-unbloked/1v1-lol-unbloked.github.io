About Edge Let's Surf

Edge Let's Surf is a endless runner games game where the difference between a clean run and a wipeout is usually one late input. It's a HTML5, JavaScript title, made by Microsoft. Somewhere around 30M+ plays so far, for what that's worth.

How to Play Edge Let's Surf

We don't have a confirmed control list for Edge Let's Surf. Most browser games in this category respond to arrow keys or WASD for movement and the mouse or space bar for the main action, so start there.

Tips for Edge Let's Surf

  • Braking a beat before the turn, not during it, keeps you from losing control.
  • Small corrections beat sharp ones almost every time.
  • The first stretch usually plays out the same way each run — learn it and the rest gets easier.

Why Play Edge Let's Surf Here

You click play and Edge Let's Surf starts. That's really the whole pitch for this page.
