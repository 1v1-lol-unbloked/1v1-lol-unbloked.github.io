How to Play Super Liquid Soccer

Super Liquid Soccer's controls aren't documented on our end. Try the obvious stuff first — WASD, arrows, click, space — the game usually makes it clear once you're moving.

Tips for Super Liquid Soccer

  • The first stretch usually plays out the same way each run — learn it and the rest gets easier.
