Drift Boss

Overview

About Drift Boss

Drift Boss is a endless runner games game where the difference between a clean run and a wipeout is usually one late input. Under the hood, it's running HTML5, JavaScript. Somewhere around 50M+ plays so far, for what that's worth.

How to Play Drift Boss

We don't have a confirmed control list for Drift Boss. Most browser games in this category respond to arrow keys or WASD for movement and the mouse or space bar for the main action, so start there.

Tips for Drift Boss

  • Small corrections beat sharp ones almost every time.
  • The first stretch usually plays out the same way each run — learn it and the rest gets easier.
  • Braking a beat before the turn, not during it, keeps you from losing control.

Why Play Drift Boss Here

Drift Boss just runs in the browser here — no installer, no login wall, no fifteen-second unskippable ad before it loads.
