1V1 LOL UNBLOCKED — STATIC HTML GAME CATALOG

Upload every file and folder in this directory to your web root.
No npm install or build command is required.

Main page: index.html
Game page format: game.html?id=2
Game database: data/games.json
Target address: https://1v1-lol-unbloked.github.io/

For local testing, use a local web server because browsers may block fetch()
when index.html is opened directly from the filesystem.

Example:
  python3 -m http.server 8080
Then open http://localhost:8080

The design and frontend implementation are new. The retained game catalog and
remote game URLs come from the attached MIT-licensed MacVG project. See
LICENSE.txt for the required license notice.
